# DAS BÜRO: GitHub-Paket 04

Enthalten sind die komplette gestaltete Website, alle sieben neu gelieferten Teambilder sowie das Bürospiel Version 0.8 inklusive Ton, Pseudonymen, Best Of und Enter zum nächsten Level. Alle bisher verwendeten Fotos wurden durch den neuen Bildsatz ersetzt.

## Auf GitHub hochladen

1. Das ZIP auf deinem Computer entpacken.
2. Dein privates Repository auf GitHub öffnen.
3. Über Add file und Upload files den gesamten Inhalt des entpackten Ordners hochladen. Die ZIP-Datei selbst nicht als Website hochladen.
4. Darauf achten, dass index.html, style.css und app.js direkt auf der obersten Ebene liegen. Die Ordner assets, games und docs müssen ebenfalls erhalten bleiben.
5. Die Dateien über Commit changes speichern.

Das Repository bleibt Private. Du musst die Bilder und die Spieldatei nicht zusätzlich aus anderen ZIP-Dateien zusammensuchen.

## Auf dem Computer ansehen

index.html im Browser öffnen. Alle Dateien müssen zusammen im entpackten Ordner bleiben.

Die Navigation verwendet URL-Fragmente. Das Spiel ist auf seiner eigenen Unterseite eingebunden und lässt sich auch in einem eigenen Fenster öffnen.

## Zugriff auf die fertige Online-Website

Dieses Paket ist vollständig zum Hochladen in das private Repository. Der Anschluss des geschützten Hostings und der persönlichen Anmeldung ist noch offen.

Ein privates Repository macht eine daraus veröffentlichte Website nicht automatisch privat. Für euren gewünschten Zugriffsschutz muss das gewählte Hosting die gesamte Website vor der Auslieferung prüfen, einschliesslich Bildern und Spieldatei. Die Anmeldemaske in diesem Entwurf leistet das noch nicht.

GitHub Pages daher für dieses Paket nicht als öffentliche Veröffentlichung einschalten. Die bestehende private Vorschau bleibt unabhängig davon nur für den freigegebenen Zugriff zugänglich.

## Spiel und gemeinsame Bestenliste

Das Spiel in games/das-buero.html ist die unveränderte Version 0.8 aus dem Bürospiel-Chat.

Bereits enthalten:

- Alle zehn Levels und die vorhandene Zeitmessung
- Pseudonym-Eingabe unter PLAYER
- Lokale Bestleistungen unter BEST OF
- Enter zum nächsten Level nach einem bestandenen Job
- Der eingebettete Ambient-Ton

Die gemeinsame Online-Tabelle ist technisch vorbereitet und noch nicht mit einer Datenbank verbunden. Ohne diese Verbindung bleiben die Bestleistungen auf dem jeweiligen Gerät.

Für die Einrichtung liegen im Ordner docs:

- BESTENLISTE_EINRICHTEN.md mit den angepassten Schritten für dieses Paket
- The_Office_Leaderboard_Setup.sql mit der Datenbankstruktur
- The_Office_Online_Setup_Original.md als Originalanleitung aus dem Spiel-Chat

Die Bestenlisten-Verbindung ist unabhängig von der Anmeldung zur Büro-Website und vom Teamchat.
