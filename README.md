# DAS BÜRO · Öffentliche Website

Die Website, das Spiel und die gemeinsame Best-of-Liste funktionieren ohne Anmeldung und ohne Gastkonto. Alle Unterseiten sind direkt über ihre Links erreichbar. Der Suchmaschinen-Ausschluss mit noindex bleibt aktiv.

Im Spiel wird ein frei gewähltes Pseudonym angezeigt. Alle gestarteten Versuche bleiben lokal erhalten und werden mit dem gemeinsamen Speicher synchronisiert. Eine zufällige Gerätekennung ordnet neue Versuche zu; dafür ist keine Registrierung nötig.

Auch der Chat ist ohne Anmeldung erreichbar. Der dort angezeigte Name ist frei wählbar.

index.html und buero-config.json gehören auf die oberste Ebene des Repositorys. Der Dienst enthält keine geheimen Schlüssel im Browser.
